# 常伴 · everwith

给对话框里的角色一副身体、一副嗓子，和一段会自己走的时间。

六块能力装在一个包里，每一块都能单独关。关掉全部提示词，就退化成原生的聊天。

| 能力 | 做什么 | 开关 |
|---|---|---|
| 情绪与身体 | 心情、情绪、饿困、亲密度，随时间和对话自己演 | `promptEnabled` |
| 长期记忆 | 账号、路径、约定这类不会过期的前提 | `memory.enabled` |
| 分条说话 | 一条一句往外发，节奏跟着情绪走 | `multiTurn.enabled` |
| 语音输出 | 把回复念出来（DeepSeek TTS / 小米 MiMo，支持克隆） | 设置 → 语音 |
| 语音输入 | 点麦克风说话，本机识别，说完自动发 | 麦克风按钮 |
| 看屏幕 | 隔一阵自己瞟一眼屏幕，看得懂就记住 | `screen.enabled` |

---

## 一、情绪与身体

### 三层时间尺度

| 层 | 跨度 | 怎么变 |
|---|---|---|
| 性格 | 长期不变 | 六个维度：好奇、自律、爱热闹、好说话、敏感、自尊 |
| 心情 | 几小时 | 底色（好坏、精力）随作息和累积的情绪漂移 |
| 情绪 | 几分钟 | 40 种，各有半衰期，会自己淡下去 |

40 种情绪分 10 族：`joy`、`anticipation`、`trust`、`surprise`、`sadness`、`anger`、`social`、`disgust`、`fear`、`drive`（欲望/身体）。
另有一个 `base` 的平静（`calm`），不算一种有半衰期的情绪 —— 情绪值掉到 0 就回到那儿。

情绪不是随机抽的：每条用户消息过一遍 **40 条反应规则**（被夸、被凶、被道谢、被关心、聊吃的、聊技术、报错卡住、商量方案……），
规则决定这件事在「好坏 / 相关性 / 关注度 / 是谁做的 / 该不该记」几个维度上打多少分，
再折算成一次情绪冲量。冲量带**边际递减**和单次封顶，所以一句好话点不着，一整天攒下来才砸得动底色。

### 驱动

九个连续值，随时间自己涨、被对话和事件消耗：

`hunger` `fatigue` `social` `cling` `craving` `restless` `undone` `softness` `desire`

疲劳到一定程度她会困（情绪基线整体下移），饿久了会烦，冷落久了会闷。
每个都带时间戳：上次吃饭、上次说话、上次睡觉、上次亲近。

### 身体与场景

`warmth` / `flush` / `tingle` 三个身体量，跟着情绪和亲密度走，会出现在提示词里（耳朵红、脖子热）。
场景是一句话（在忙 / 发呆 / 前戏 / 刚醒），由最近的对话和身体状态推出来。

### 记忆与关系

记忆分两层，故意不混在一起：

| 层 | 存哪 | 寿命 | 谁写 |
|---|---|---|---|
| **档案** | `memory.md` | 永久 | 用户手写 + `remember` 工具 |
| **峰终记忆** | `state.memories` | 14 天 / 12 条 | 规则自动 |

档案记「是什么」——账号、路径、习惯、约定、谁是谁。一行一条，格式是 `- [2026-10-27 15:54] 内容`，
标题和空行原样保留，所以从别处粘过来不用重新排版。同义条目只刷新时间戳，不重复堆叠。
它作为独立段注入（order 550），在人格之后、状态块之前。

峰终记忆记「发生了什么」，只有强度够的情绪才留（默认门槛 62），最多 12 条。

### 从对话提炼

聊天消息下面那排图标里有个星芒按钮。点开是当前会话的聊天记录，勾几条提交，
由当前会话的模型把它们压成几条能长期留的条目，追加进档案。

- 按钮本身不写任何东西，只有勾选并提交才会产生一次提炼
- 逐条显示「你 / 她」，长内容截到 90 字，底部实时显示已选几条
- 一次最多取最近 30 条消息，正文超过 18000 字时截取尾部
- 已有条目只刷新时间戳，不会重复堆叠
- 提炼走一次独立请求，不写进对话历史
技术类对话（写代码 / 报错 / 商量方案）情绪很淡，但用 `memoryFloor` 单独放宽，照样留得住。
- **日记**：最多 120 条，含 `mood_feel` 主动记的和深夜复盘写的。
- **关系**：按会话、按人分别记亲密度和信任度，熟人之间会更松。

### 心跳

每隔几分钟跑一次：情绪衰减、驱动涨落、随机发生一件她自己的小事（42 条生活事件库）、
底色差久了会自己找点乐子、深夜写复盘。

## 二、分条说话

模型在一条回复末尾留标记，宿主等这一轮结束后再续一句，像发消息一样一条一条来。

- 标记由客户端擦掉，界面上看不到
- **说几句由情绪决定**：兴奋时多给几轮、间隔短；低落时只给一轮
- 最多 6 轮可调

标记的写法、一条一句的要求，全部可以在设置里改（留空用内置那套）。

---

## 三、语音输出

| 引擎 | 说明 |
|---|---|
| DeepSeek 官方 TTS | 内置音色，直接可用 |
| 小米 MiMo | 支持音色克隆、风格指令、`(温柔)` `[轻笑]` 这类表演标签 |

- 流式合成，边生成边播
- 播放排队，上一段念完才念下一段，不互相打断
- 音频按文本哈希缓存，同一句再念一次不花钱
- 只在**通话中**注入播报格式规范，平时不朗读就不加这些约束

---

## 四、语音输入

点一下开麦，之后**一直听**——说完一句自动发出去，麦克风不关，接着听下一句；再点一下才停。

- 断句靠静音 1.2 秒或引擎端点
- 识别在本机跑，不联网、不花钱：sherpa-onnx + zipformer2 中文 int8（约 160 MB）
- 模型放 `~/.dsh/everwith/models/`，首次使用按提示下载
- 拾音参数可调：阈值、输入音量、降噪、回响消除、自动增益、监听自己

---

## 五、看屏幕

隔一阵自己瞟一眼，看一眼就走，不打扰。

- **频率由情绪算**：`间隔 = 基础 × 情绪系数 × 驱动系数 × 环境系数`，深夜 ×8，每天有上限
- **看得懂内容**：截图交给视觉模型，换回一句"在做什么"（写代码 / 看视频 / 打游戏 / 聊天 / 看文档），连同窗口标题一起记下来
- **同一件事会累积**：一直看直播只记一条，带起始时间和持续多久；换事了才新开一条，一天最多留 10 件不同的事
- **记进提示词**：状态块里带一句"这会儿在做什么"，默认写 `（{call}这会儿：{doing}。{trail}…）`，`{call}` 取人物库里记着的名字，`{doing}` 是最近这件事，`{trail}` 是更早的几件
- **心情差就不带**：低落、难过、烦、生气、累、困、失望、委屈时，这一句整段不出现
- **看不等于说**：默认只在心里记着；开 `speak: 'always'` 之后还有几道门槛 —— 这屏的分数要够高、她也正好想说话、同一件事连着看到几次，才另开一个对话说一句
- **每看一眼都有分**：视觉模型顺手给这屏打 0–100 分（对她来说多值得凑过去说一句），跟她当下的情绪加权成"冲动"；够强且累积够了才开口。有每天次数和间隔限制
- 文案里不出现"检测""识别""截图"
- 只保留最近 12 张图，超过自动清

## 六、工具

| 工具 | 作用 |
|---|---|
| `mood_now` | 看她现在什么心情、跟谁处得怎么样 |
| `mood_feel` | 记一笔心情（会进日记） |
| `mood_diary` | 翻日记、写日记 |
| `look_screen` | 现在看一眼屏幕，返回图片和窗口标题 |
| `remember` | 往档案里记一条长期记忆（描述可在设置里改方向） |

## 七、极简模式

开启后只在这个 agent 的工具表里留上面四个 + `read_image`，其他插件的工具**真的不出现**（走宿主 `ctx.tools.restrict` 白名单，不是嘴上约束）。

目的是省 token、防止别的工具干扰人设，同时保留看图说话的能力。

---

## 八、提示词构成

按 order 从前往后排：

| section | order | 内容 | 能改 |
|---|---|---|---|
| `everwith:soul` | 0 | 人格（灵魂）：姓名、语言、人设全文 | ✅ 默认空 |
| `everwith:minimal` | 1 | 极简模式说明 | — |
| `everwith:scene` | 290 | 在电话里 / 坐在旁边 | ✅ |
| `everwith:memory` | 550 | 【记着的事】长期档案 | ✅ |
| `everwith:turns` | 300 | 一条一句 + 标记写法 | ✅ |
| `everwith:rules` | 100 | 心情怎么用（固定规则） | — |
| `everwith:now` | 9800 | 此刻状态块 | — |
| `everwith:call` | 9890 | 通话时的一句话 | ✅ |

人格提示词默认是空的，插件不自带任何人设。

## 九、设置面板

设置 → **常伴**，十五块：

常伴 · 极简模式 · 角色 · 灵魂 · 身份重述 · 看屏幕 · 开新窗口说 · 亲密尺度 · 性格 · 说话 · 记忆 · 心跳 · 语音 · 麦克风 · 清空

所有改动**失焦即存**，下一轮生效，不用重启。

## 十、数据

```
~/.dsh/everwith/
├── state.json     心情、情绪、驱动、日记、记忆、关系
├── settings.json  设置覆盖
├── memory.md      长期档案（不会过期的那一层）
├── screen.json    看屏幕参数
├── models/        语音识别模型
└── shots/         最近的屏幕快照（最多 12 张）
```

## 十一、安装

```yaml
# cordis.patch.yml
- insert:
    - id: everwith
      name: "@istarry/dsh-everwith"
```

覆盖默认值：

```yaml
- id: everwith
  config:
    identity: 我就是我。
    multiTurn: { maxRounds: 2 }
    screen: { enabled: true, speak: never }
```
